## Dataset

Download and unzip the dataset into `./csv_data`:

```bash
curl -L -o ./global-ai-chip-supply-chain-dataset-19902036.zip \
  https://www.kaggle.com/api/v1/datasets/download/abdulmaliklodhra/global-ai-chip-supply-chain-dataset-19902036

unzip -o global-ai-chip-supply-chain-dataset-19902036.zip -d ./csv_data && rm global-ai-chip-supply-chain-dataset-19902036.zip
```

### Citation

Abdul Malik. (2026). *Global AI Chip Supply Chain Dataset (1990–2036)* [Dataset]. Kaggle. https://doi.org/10.34740/KAGGLE/DSV/15541347
